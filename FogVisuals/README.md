# FogVisuals

Клиентский мод для **Minecraft 26.3 (Fabric)**, переписанный и переименованный из SoupAPI.
Фокус — туман: свой цвет и плотность, биомная окраска, пульсация, пресеты и чистый горизонт.

## Возможности

- **Custom Fog** — свой цвет (RGB), плотность, дальность начала/конца тумана.
- **Biome Fog** — цвет тумана подмешивает цвет воды биома (тунца по силе), ночью туман темнеет вместе с миром.
- **Fog Pulse** — туман «дышит»: настраиваемые глубина и скорость пульсации.
- **Clear Vision** — полностью отодвигает ванильный туман (дальность настраивается).
- **8 пресетов** (Mist, Dense, Underwater, Inferno, Toxic, Blood Moon, Void, Candy) + Custom.
- **Горячие клавиши**: `O` — click-GUI меню, `V` — переключение пресетов на лету (сообщения в actionbar).
- **Click-GUI** в стиле современных клиентских модов: тёмная перетаскиваемая панель,
  сайдбар с вкладками (Пресеты / Туман / Эффекты / Цвет), кастомные тумблеры и
  слайдеры, живой превью цвета тумана. Рисуется вручную через рендер-API 26.3.

## Версии

| Компонент | Версия |
|---|---|
| Minecraft | 26.3 |
| Fabric Loader | 0.20.1 |
| Fabric API | 0.166.0+26.3 |
| Loom | 1.19.4 (no-remap плагин `net.fabricmc.fabric-loom`) |
| Gradle | 9.9.0 (wrapper) |
| Java | 25 |

Начиная с 26.x Minecraft поставляется необфусцированной, поэтому проект использует
официальные имена Mojang без отдельных маппингов. Из-за этого применяется
no-remap вариант плагина Loom и обычные конфигурации зависимостей
(`implementation` вместо `modImplementation`).

## Сборка

Нужна **JDK 25** (JAVA_HOME). Затем:

```bash
gradlew.bat build        # Windows
./gradlew build          # Linux/macOS
```

Готовый jar появится в `build/libs/FogVisuals-1.0.0.jar`.

## Установка

1. Установите Fabric Loader 0.20.1+ для Minecraft 26.3
2. Положите `FogVisuals-1.0.0.jar` и [Fabric API](https://modrinth.com/mod/fabric-api) (0.166.0+26.3) в папку `mods`
3. В игре: `O` — click-GUI меню, `V` — переключение пресетов

## Отличия от SoupAPI

SoupAPI был большим клиентским API (TargetHUD, трейлы, плащи, Discord RPC и т.д.) на 1.21.4.
В FogVisuals осознанно оставлена только туманная часть — она портирована на новый
рендер 26.3 (fog переехал на `FogRenderer`/`FogData` с environment-атрибутами, а
FogShape был удалён), остальное вынесено за рамки проекта.
